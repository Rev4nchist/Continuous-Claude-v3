# Legacy briefs and labs

Brief and lab digests remain derivative outputs. They are never proof that a playlist was
fully processed and cannot replace the coverage audit or exhaustive outlines.

Use the current corpus search and citations, then create one of:

- `brief`: implications, demonstrated versus asserted evidence, ADOPT/WATCH/SKIP verdicts,
  integration sketch, and timestamped source table.
- `lab`: falsifiable hypothesis, cited prior art, method, numerical success criteria, kill
  criteria, and smallest first commit.

Write under `docs/research/youtube/_digests/`, retain `[vid:<id> @<timestamp>]` citations,
and run `publish.mjs` only when the user explicitly requests Notion publication. Public
digests paraphrase by default. Do not include full transcripts or republish screenshots.
