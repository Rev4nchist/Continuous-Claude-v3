How you would work this board

The interaction model this prototype argues for. Everything below runs from a terminal first; the browser earns write access only where a terminal genuinely can't reach.

Open

A lane before a session

Nothing starts without a lane. Declaring scope up front is what turns overlap from a collision you discover into a query you can run.

ccb open coordination-repair --scope '.claude/hooks/src/**' --project ccv3

ccw coordination-repair then creates the worktree, exports the terminal id, and launches the session already attached.

Attach

Sessions are badges, not rows

A session attaches to a lane and detaches when it ends. Compaction, /clear, a crash, or a night's sleep changes the badge — never the lane.

  • live — heartbeat inside 5 minutes
  • idle — attached, quiet
  • detached — lane open, nobody home
Detect

Overlap before it happens

Two lanes with intersecting scope is one query over about six rows — not a scan of 8,179 file claims after the damage.

Same terminal is a warn; a stranger on infra scope is a block; docs are advisory. Posture is a column on the lane, not a hardcoded path list.

Answer

The one thing worth a browser

A session hits a permission prompt in a terminal you aren't watching and waits — silently, indefinitely, holding a worktree.

Nothing records that today. Capturing it is the cheapest high-value instrument missing, and “2 lanes waiting on you, oldest 47 min” is the line that justifies the app.

Close

Done means merged

Worktree-per-session means N branches. Five branches are unmerged right now and no existing view shows it.

A lane closes on its stated done-condition, and the board keeps the unmerged count in your face until it does.

Trust

Every number is falsifiable

This system has shipped pipelines that reported success while silently failing. So the board never renders a confident zero where the honest answer is not measured.

Four states, always distinguished: a value, a real zero, stale, unavailable — with the reconciling query printed beside it.
